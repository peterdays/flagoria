Footstep files are procedural filtered noise (numpy), mono 16-bit 22.05 kHz, 0.22–0.34 s,
RMS-normalized to about -20 dBFS with peaks below -0.3 dBFS. Regenerate with:

    python3 tools/audio/gen_footsteps.py art/audio/sfx/footsteps

Ninja Adventure files are copied from `art/Sprites/NinjaAdventure/Sounds/Game/` (combat) and `art/Sprites/NinjaAdventure/Sounds/Menu/` (UI) (license: `art/Sprites/NinjaAdventure/LICENSE.txt`),
converted to mono 16-bit 22.05 kHz, trimmed, and RMS-normalized to about -20 dBFS. Generated files use the same format and level.

Mob files are procedural (numpy: swept sines, filtered noise, formant-filtered pulses), mono 16-bit 22.05 kHz,
RMS-levelled to about -20 dBFS (idle about -26 dBFS). Regenerate with:

    python3 tools/audio/gen_mobs.py art/audio/sfx/mobs

UI files are built by `tools/audio/gen_ui.py` (run from the repository root), mono 16-bit 22.05 kHz,
RMS-levelled to about -22 dBFS, a little under gameplay. Regenerate with:

    python3 tools/audio/gen_ui.py art/audio/sfx/ui

World files are built by `tools/audio/gen_world.py` (run from the repository root), mono 16-bit 22.05 kHz,
RMS-levelled to about -20 dBFS (regen tick about -30 dBFS). Regenerate with:

    python3 tools/audio/gen_world.py art/audio/sfx/world
